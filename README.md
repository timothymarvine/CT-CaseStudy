# Hani & Andi Wedding Invitation

Website undangan pernikahan digital untuk Hani & Andi

Project ini dibuat menggunakan HTML, CSS, JavaScript, dan beberapa library tambahan sesuai ketentuan yang diberikan.

---

## Features

Website ini memiliki beberapa fitur utama:

- Opening Invitation
- Background Music
- Hero Section
- Wedding Quote
- Bride & Groom Information
- Wedding Countdown
- Wedding Location
- Interactive Photo Gallery
- RSVP Section
- Wedding Wishes / Personal Messages
- Thank You Section
- Smooth Navigation
- Scroll Animation
- Responsive Layout

---

## Tech Stack

Project ini menggunakan stack berikut:

- **HTML5**  
  Digunakan untuk membangun struktur utama website.

- **Bootstrap 4.6.2**  
  Digunakan untuk utility layout seperti flex, alignment, dan responsive layout.

- **jQuery 3.4.1**  
  Digunakan untuk menangani interaksi pada halaman seperti Open Invitation, manipulasi elemen, serta integrasi Fancybox.

- **AOS 2.3.1**  
  Digunakan untuk memberikan animasi ketika elemen muncul saat halaman di-scroll.

- **Swiper 11**  
  Digunakan untuk membuat galeri foto dalam bentuk slider/carousel.

- **Fancybox 3.5.7**  
  Digunakan untuk menampilkan foto galeri dalam tampilan popup/lightbox.

- **Custom CSS**  
  Digunakan untuk menyesuaikan seluruh tampilan website sesuai desain undangan.

- **JavaScript**  
  Digunakan untuk countdown, background music, opening invitation, Swiper, Fancybox, dan interaksi lainnya.
